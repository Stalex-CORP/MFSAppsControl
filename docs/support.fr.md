# Support

## Communauté Discord

Tout le support de MFSAppsControl se fait sur le **Discord**, dans le salon
dédié **#mfsappscontrol** (Pensez à activer le rôle à votre arrivée).

Ce salon contient un **modèle prêt à l'emploi** pour signaler un bug ou proposer une fonctionnalité.

[:fontawesome-brands-discord: **Rejoindre le Discord**](https://discord.gg/peNzhxVPj3){ .md-button .md-button--primary }

## Signaler un problème

Pour qu'un problème puisse être diagnostiqué, indiquez :

- votre version de **Windows** et de **MFSAppsControl** (visible dans [Options](options.md) → **À propos**) ;
- la version du **simulateur** (2024 ou 2020) ;
- les **étapes** pour reproduire le problème ;
- le comportement **attendu** et le comportement **observé**.

## Joindre un rapport de diagnostic

Les journaux font gagner énormément de temps à l'analyse.

La procédure à suivre :

1. Dans les [Options](options.md) → **Débogage**, réglez le **niveau de
   journalisation** sur **Debug** (ou **Trace** si le support vous le demande).
2. **Reproduisez le problème** — refaites exactement les manipulations qui
   posent souci.
3. Toujours dans **Débogage**, cliquez sur **Exporter les logs**, et
   enregistrez le fichier `.zip` proposé.
4. **Joignez ce `.zip`** à votre message sur le Discord.
5. Une fois terminé, remettez le niveau sur **Erreur**.

!!! info "Que contient l'export ?"
    Le `.zip` regroupe **les journaux générés** et votre fichier de **configuration**.<br>
    Rien d'autre n'est collecté, et rien n'est envoyé automatiquement : vous seul décidez de le partager.

## Proposer une fonctionnalité

Les suggestions sont les bienvenues sur le Discord.<br>
Décrivez **le besoin** en suivant le modèle (ce que vous cherchez à faire avant ou pendant un vol) plutôt que la solution technique.
Je ne peux pas garantir que toutes les idées seront implémentées, mais elles seront toutes lues et considérées.
