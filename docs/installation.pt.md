# Instalação

## Requisitos

- **Windows 10 ou 11 (64 bits)**
- **Microsoft Flight Simulator 2024 e/ou 2020** (instalado)
- **WebView2** — presente de origem no Windows 11 e nos Windows 10 atualizados. Se necessário, o instalador transfere-o automaticamente.
- **SimConnect (incluído no simulador)** — A deteção «pronto para voar» usa o SimConnect para saber se o simulador está pronto para receber as aplicações.

## Transferir

O MFSAppsControl está disponível em:

- [:material-download: **Flightsim.to**](https://fr.flightsim.to/addon/96593/mfs-apps-control)

## Instalar

1. Execute o instalador transferido.
2. Se o Windows SmartScreen mostrar um aviso «O Windows protegeu o seu PC»,<br>
  clique em **Mais informações** e depois em **Executar mesmo assim**.<br>
  É um comportamento de prevenção normal para uma aplicação recente, que precisa de várias instalações para ser reconhecida pela Microsoft.
3. Siga o assistente passo a passo para concluir a instalação.

!!! tip "Atualizações"
    Depois de instalada, a aplicação **avisa-o quando houver uma nova versão disponível** (emblema e notificação).<br>
    Poderá transferi-la e instalá-la diretamente a partir da aplicação, clicando no emblema ou através das opções.

## Primeiro arranque

No primeiro arranque, o MFSAppsControl abre num **perfil vazio** por predefinição.<br>
Siga a [**Introdução**](getting-started.md) para adicionar as suas primeiras aplicações.

## Desinstalar

Vá a<br>
**Definições do Windows → Aplicações → Aplicações instaladas → MFSAppsControl → Desinstalar**.


!!! tip "Limpeza completa"
    A sua configuração **não é eliminada** se não assinalar a opção de eliminação dos dados: os seus perfis são mantidos se voltar a instalar.
