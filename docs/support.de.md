# Support

## Discord-Community

Der gesamte Support für MFSAppsControl läuft über **Discord**, im dafür
vorgesehenen Kanal **#mfsappscontrol** (denken Sie daran, sich bei Ihrer Ankunft die Rolle zuzuweisen).

Dieser Kanal enthält eine **fertige Vorlage**, um einen Fehler zu melden oder eine Funktion vorzuschlagen.

[:fontawesome-brands-discord: **Discord beitreten**](https://discord.gg/peNzhxVPj3){ .md-button .md-button--primary }

## Ein Problem melden

Damit ein Problem eingegrenzt werden kann, geben Sie bitte an:

- Ihre Version von **Windows** und von **MFSAppsControl** (sichtbar in [Optionen](options.md) → **Über**);
- die Version des **Simulators** (2024 oder 2020);
- die **Schritte**, mit denen sich das Problem reproduzieren lässt;
- das **erwartete** und das **beobachtete** Verhalten.

## Einen Diagnosebericht anhängen

Die Protokolle sparen bei der Analyse enorm viel Zeit.

So gehen Sie vor:

1. Stellen Sie in den [Optionen](options.md) → **Fehlersuche** die
   **Protokollstufe** auf **Debug** (oder **Trace**, wenn der Support Sie darum bittet).
2. **Reproduzieren Sie das Problem** — führen Sie genau die Schritte erneut aus,
   die Schwierigkeiten machen.
3. Klicken Sie weiterhin unter **Fehlersuche** auf **Logs exportieren** und
   speichern Sie die angebotene `.zip`-Datei.
4. **Hängen Sie diese `.zip`** an Ihre Nachricht im Discord an.
5. Stellen Sie die Stufe anschließend wieder auf **Fehler**.

!!! info "Was enthält der Export?"
    Die `.zip` bündelt **die erzeugten Protokolle** und Ihre **Konfigurationsdatei**.<br>
    Sonst wird nichts erfasst, und nichts wird automatisch versendet: Nur Sie entscheiden, ob Sie sie teilen.

## Eine Funktion vorschlagen

Vorschläge sind im Discord jederzeit willkommen.<br>
Beschreiben Sie **den Bedarf** anhand der Vorlage (was Sie vor oder während eines Fluges erreichen möchten) statt der technischen Lösung.
Ich kann nicht versprechen, dass jede Idee umgesetzt wird, aber alle werden gelesen und geprüft.
