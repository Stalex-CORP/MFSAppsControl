# Installation

## Prérequis

- **Windows 10 ou 11 (64 bits)**
- **Microsoft Flight Simulator 2024 et/ou 2020** (installé)
- **WebView2** — présent nativement sur Windows 11 et les Windows 10 à jour. Si besoin, l'installeur le télécharge automatiquement.
- **SimConnect (inclus dans le simulateur)** — La détection « prêt à voler » utilise SimConnect pour savoir si le simulateur est prêt à recevoir les applications.

## Télécharger

MFSAppsControl est disponible sur :

- [:material-download: **Flightsim.to**](https://fr.flightsim.to/addon/96593/mfs-apps-control)

## Installer

1. Lancez l'installeur téléchargé.
2. Si Windows SmartScreen affiche un avertissement « Windows a protégé votre ordinateur »,<br>
  cliquez sur **Informations complémentaires** puis **Exécuter quand même**.<br>
  C'est un comportement de prévention normal pour une application récente qui nécessite plusieurs installations pour être reconnue par Microsoft.
3. Suivez l'assistant étape par étape pour l'installation.

!!! tip "Mises à jour"
    Une fois installée, l'application vous **préviendra quand une nouvelle version est disponible** (badge et notification).<br>
    Vous pourrez la télécharger et l'installer directement depuis l'application en cliquant sur le badge ou via les options.

## Premier lancement

Au premier démarrage, MFSAppsControl s'ouvre sur un **profil vide** par défaut.<br>
Suivez la [**Prise en main**](getting-started.md) pour ajouter vos premières applications.

## Désinstaller

Passez par<br>
**Paramètres Windows → Applications → Applications installées → MFSAppsControl → Désinstaller**.


!!! tip "Nettoyage complet"
    Votre configuration **n'est pas supprimée** si vous ne cochez pas l'option de suppression des données : vos profils sont donc conservés si vous réinstallez.
