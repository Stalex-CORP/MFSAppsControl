# Instalación

## Requisitos

- **Windows 10 u 11 (64 bits)**
- **Microsoft Flight Simulator 2024 y/o 2020** (instalado)
- **WebView2** — presente de forma nativa en Windows 11 y en los Windows 10 actualizados. Si hace falta, el instalador lo descarga automáticamente.
- **SimConnect (incluido en el simulador)** — La detección «listo para volar» usa SimConnect para saber si el simulador está preparado para recibir las aplicaciones.

## Descargar

MFSAppsControl está disponible en:

- [:material-download: **Flightsim.to**](https://fr.flightsim.to/addon/96593/mfs-apps-control)

## Instalar

1. Ejecuta el instalador descargado.
2. Si Windows SmartScreen muestra el aviso «Windows ha protegido su PC»,<br>
  haz clic en **Más información** y luego en **Ejecutar de todas formas**.<br>
  Es un comportamiento de prevención normal para una aplicación reciente, que necesita varias instalaciones antes de ser reconocida por Microsoft.
3. Sigue el asistente paso a paso para completar la instalación.

!!! tip "Actualizaciones"
    Una vez instalada, la aplicación **te avisará cuando haya una nueva versión disponible** (insignia y notificación).<br>
    Podrás descargarla e instalarla directamente desde la aplicación haciendo clic en la insignia o desde las opciones.

## Primer inicio

En el primer arranque, MFSAppsControl se abre con un **perfil vacío** de forma predeterminada.<br>
Sigue los [**Primeros pasos**](getting-started.md) para añadir tus primeras aplicaciones.

## Desinstalar

Ve a<br>
**Configuración de Windows → Aplicaciones → Aplicaciones instaladas → MFSAppsControl → Desinstalar**.


!!! tip "Limpieza completa"
    Tu configuración **no se borra** si no marcas la opción de eliminación de los datos: tus perfiles se conservan si vuelves a instalar la aplicación.
