# Installation

## Voraussetzungen

- **Windows 10 oder 11 (64 Bit)**
- **Microsoft Flight Simulator 2024 und/oder 2020** (installiert)
- **WebView2** — auf Windows 11 und aktuellen Windows-10-Systemen bereits vorhanden. Falls nötig, lädt das Installationsprogramm die Komponente automatisch herunter.
- **SimConnect (im Simulator enthalten)** — die Erkennung „Startbereit“ nutzt SimConnect, um festzustellen, ob der Simulator bereit ist, die Anwendungen aufzunehmen.

## Herunterladen

MFSAppsControl ist erhältlich auf:

- [:material-download: **Flightsim.to**](https://fr.flightsim.to/addon/96593/mfs-apps-control)

## Installieren

1. Starten Sie das heruntergeladene Installationsprogramm.
2. Falls Windows SmartScreen die Warnung „Der Computer wurde durch Windows geschützt“ anzeigt,<br>
  klicken Sie auf **Weitere Informationen** und dann auf **Trotzdem ausführen**.<br>
  Das ist ein normales Schutzverhalten bei einer neuen Anwendung, die erst nach mehreren Installationen von Microsoft als vertrauenswürdig eingestuft wird.
3. Folgen Sie dem Assistenten Schritt für Schritt durch die Installation.

!!! tip "Updates"
    Nach der Installation **meldet Ihnen die Anwendung, sobald eine neue Version verfügbar ist** (Badge und Benachrichtigung).<br>
    Sie können sie direkt aus der Anwendung heraus herunterladen und installieren, indem Sie auf den Badge klicken oder die Optionen verwenden.

## Erster Start

Beim ersten Start öffnet MFSAppsControl standardmäßig ein **leeres Profil**.<br>
Folgen Sie den [**Ersten Schritten**](getting-started.md), um Ihre ersten Anwendungen hinzuzufügen.

## Deinstallieren

Gehen Sie über<br>
**Windows-Einstellungen → Apps → Installierte Apps → MFSAppsControl → Deinstallieren**.


!!! tip "Vollständige Bereinigung"
    Ihre Konfiguration wird **nicht gelöscht**, wenn Sie die Option zum Entfernen der Daten nicht aktivieren: Ihre Profile bleiben also erhalten, wenn Sie neu installieren.
